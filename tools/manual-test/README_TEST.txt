TeyPdfCad — минимальный ручной тест

1. Дважды щёлкните START_TEST.cmd.
2. Выберите исходный PDF в появившемся окне.
3. Дождитесь окончания конвертации.

Больше ничего вводить не нужно.

Скрипт автоматически:
- создаёт отдельную папку Results рядом с пакетом;
- запускает TeyPdfCad.Cli;
- сохраняет основной DWG, JSON-отчёт, run.log и BUILD_INFO.txt с точным SHA сборки;
- сохраняет отдельный *_DIAGNOSTIC_PROBE_DO_NOT_USE.dwg: он нужен разработчику для проверки native DIMENSION и содержит исходную геометрию вместе с probe-кандидатами; как конечный DWG его использовать нельзя;
- перед запуском сверяет SHA-256 TeyPdfCad.Cli.exe с BUILD_INFO.txt, чтобы исключить повреждённую/подменённую сборку;
- записывает SHA-256 выбранного PDF и EXE в run.log, чтобы результат можно было воспроизвести;
- открывает JSON-отчёт;
- пытается открыть готовый DWG программой, связанной с .dwg (обычно AutoCAD).

Если результат помечен PARTIAL, DWG всё равно создаётся, но его нужно визуально проверить.
Если PDF оказался сканом/растром без пригодной векторной геометрии, пакет сообщит об этом отдельно.
Если возникла ошибка, передайте разработчику всю созданную папку результата или минимум run.log + JSON.

Дополнительная проверка native DIMENSION (только когда разработчик попросит):
- в ZIP уже лежит проверенный по SHA-256 плагин AutoCADPlugin\TeyPdfCad.AutoCAD.dll;
- откройте *_DIAGNOSTIC_PROBE_DO_NOT_USE.dwg;
- один раз загрузите DLL командой NETLOAD;
- выполните TEYPDFDIMMETRICS;
- файл *.dimension-metrics.json появится рядом с открытым probe DWG;
- передайте его вместе с обычным JSON-отчётом. По CandidateId они сравниваются независимым comparator'ом.
Эта дополнительная диагностика не изменяет DWG и не включает destructive suppression.

Важно:
Этот пакет проверяет текущий безопасный production-path. Разрушающее удаление исходной PDF-геометрии остаётся заблокированным, пока независимые source-equivalence и quality gates не подтверждены.
